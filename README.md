# Miraculous RP Bot — v2

بوت رول بلاي لميراكولوس بالأزرار فقط (ثلاثة أوامر: `/panel` و`/setup` و`/backup`).

## التشغيل
1. `pip install -r requirements.txt`
2. انسخ `.env.example` إلى `.env` وضع التوكن.
3. فعّل **Server Members Intent** في Discord Developer Portal.
4. `python main.py`
5. في أي قناة: `/panel` (للحراس/المشرفين)، ثم `/setup` اختياريًا.

بيانات السيرفرات القديمة (`data/*.json`) تعمل كما هي؛ الحقول الجديدة تُضاف تلقائيًا.

## الملفات
| الملف | الدور |
|---|---|
| `main.py` | تشغيل البوت، المهام الخلفية (انتهاء التحول، كشف الهوية، استرجاع الخامل)، الأوامر |
| `views.py` | لوحة اللاعب وكل ما يفتحه (تحول، قوى، Unify، الشفاء، مبارزة، سرقة، إطعام، طلبات…) |
| `guardian.py` | لوحة الحارس، الإعدادات، الأزمات، معالج `/setup` |
| `logic.py` | منطق اللعبة والـ Embeds المشتركة |
| `storage.py` | الحفظ مع قفل لكل سيرفر وكتابة ذرّية |
| `miraculous_data.py` | بيانات الميراكولوس، العبارات الأصلية، الثوابت (المؤقتات، الدمج…) |
| `i18n.py` | النصوص بالإنجليزية والعربية |

## ملاحظات
- عبارات التحول/إلغاء التحول تبقى بالإنجليزية كما في المسلسل. العبارات غير المكشوفة رسميًا
  (إلغاء تحول Ox وGoat وMonkey وRooster وPig) قيمتها `None` في `miraculous_data.py`
  ويعرض البوت مؤقتًا `<Kwami>, Power Down!` — عدّلها متى عرفتها.
- عبارات الشر (Dark Side) موجودة حاليًا لـ Black Cat فقط (`Daggers Out / Daggers In`)؛
  الباقي يستخدم العبارة العادية. أضف `dark_phrase` لأي ميراكولوس تريد.
- كل الثوابت (مدة التحول، العدّ التنازلي 5 دقائق، مهلة المقاومة، تبريد السرقة…) في `miraculous_data.py`.
- الحارس يتحكم في السرقة وكشف الهوية والجانب المظلم وطعام الكوامي ولغة السيرفر واسترجاع الخامل من **Guardian Panel ← Settings**.
